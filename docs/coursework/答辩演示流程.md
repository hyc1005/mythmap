# 山海寻踪 Demo 演示流程（约 5 分钟）

## 演示前

1. 按 README 启动前端生产预览，或打开已部署的 Demo；当前展示不需要 PostGIS、FastAPI 或 Java 服务。
2. 准备桌面和手机竖屏两种显示，确认素材已载入。图面表达篇目方位与叙事关系，不显示现代经纬网。
3. 预先选择盘古、燧人、大羿，以及一条异兽和神域详情作为示例；保留原文出处入口。用“尧禅舜”展示已复核的《论语·尧曰》20.1 引文及其原文链接。
4. 确认语言切换可用：`?lang=zh` 打开中文，`?lang=en` 打开英文；不带语言参数时沿用已保存的选择。英文详情可展开“Chinese original”查看中文原文。

## 演示顺序

1. **地图与时间轴（30 秒）**：展示地图主体和序章至七章的次序，说明这是叙事编排，图面距离不按比例绘制。简短悬浮导航栏山海印章，展示日轮升起和海纹流动。
2. **故事动画（60 秒）**：盘古进入地图章，展示燧人取火以及大羿命中定格；切换 1×/2×、暂停和重播。
3. **全屏交互（60 秒）**：展开地图工具，悬浮地点，打开原文详情；展示播放/预览分区与稳定画布，然后切章和退出全屏。
4. **神域与异兽（60 秒）**：同时打开两层，展示地图已关联条目；在异兽谱搜索并查看同名异篇的独立记录。切换 EN，展示英文搜索及中文名称检索，再展开中文原文。
5. **文献边界（60 秒）**：打开底部“读图与依据”，说明叙事顺序、经文距离、装饰山形、地点示意和插画性质；展示一条原文与出处。右侧藏书印为项目品牌图，手机上位于段落之后，不作为古本插图或文献证据。
6. **部署与复现（30 秒）**：展示 GitHub 仓库与 Demo 地址；说明前端静态部署和来源快照，按 README 可本地构建。

## 演示保障

- 首次访问时等待图片加载完成；弱网络演示优先使用本机生产预览。
- 页面素材本地提供，不依赖在线瓦片；对外原文链接仍需要联网。
- 未获经文或可靠叙事支持的位置保持示意，不把图像细节当作考据依据。
- 旧版 PostGIS 分析接口属于保留的独立课程原型，当前 Demo 页面没有该分析入口。
- 英文字体 Lora 与 Source Sans 3 随网站提供，无需安装字体软件。主要图片使用无损 WebP，原 PNG 保留在 `frontend/artwork-source/optimized-originals/`。
- 系统开启“减少动态效果”时，导航栏图标保持静态；触屏也保持静态。演示悬浮动画时应使用支持悬浮的鼠标和允许动画的系统设置。
- 演示完成后，在运行开发或预览服务的终端按 `Ctrl+C`，释放 5173 / 4173；若启动了可选 Java 服务，也应关闭其终端并释放 8081。
